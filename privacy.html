Privacy Policy

Project: VitalsLab Performance and Architecture Suite | Maintainer: Arnav Katyal | Effective Date: October 21, 2026

1. Overview and Scope

This Privacy Policy outlines how information is managed within the VitalsLab application, developed and maintained by Arnav Katyal. VitalsLab is an engineering tool designed to analyze Core Web Vitals, WCAG 2.2 accessibility compliance, and component hydration performance.

2. Client-Side and Local Processing

VitalsLab runs strictly within your local browser runtime. All audit checks, simulated metrics, contrast calculations, and diff remediations occur on the client machine:

  • No External Telemetry: Tested URLs, audit inputs, and generated report payloads are not sent to any remote tracking or advertising server.
  • No Profiling: We do not build user behavioral profiles, run third-party tracking scripts, or sell data.
  • No Tracking Cookies: VitalsLab does not set persistent tracking or profiling cookies.

3. Data Export Functionality

When you choose to use the "Export Report" feature, an audit report file (vitalslab-audit-report.json) is generated directly inside your browser using the standard Blob and object URL interfaces. This file is saved directly to your local file system.
